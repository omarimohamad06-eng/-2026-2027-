ClassKit — Teacher guide

SVT · Pr Omari Mohammed · 2026/2027

Teacher app

0Once, at the start

  1. Open the teacher app (QR above) on your laptop or phone.
  2. Choose roster / backup file… → roster-2026-2027.json. The 5 classes load (168 students).
  3. Seating → Arrange: place each student on their table for the year.
  4. Students & PINs → Print PIN slips, cut and hand out.
  5. QR cards → Print cards for each class (laminate them).
  6. Publish: put the public address, then Settings: check the barème (5/5/5/5).
  7. Stick the student poster in the classroom.
🔒 The names stay only in your browser. Never upload the roster file to GitHub.

1Attendance in 10 secondsevery lesson

  • Attendance mode: tap the student of each empty table → red. Their numbers appear in Absent student numbers → Copy numbers for the official register.
  • Each absence automatically removes 0.5 from the Absence grade. blur names before projecting.

2Points during the lesson

  1. Seating → Points, tap the student.
  2. Tap a reason (Bavardage, Bonne réponse…), then + or −.
  3. The student sees it, with date and reason, after the next Publish.

3Gradebookafter each check / contrôle

  • +/−: Participation, Organisation du cahier, Travail à rédiger.
  • Absence is calculated; its +/− only adjusts it (justified absence).
  • Type the Contrôle marks (3 columns in 2BAC SVT, 2 elsewhere); the final grade updates by itself.
Activités /20 = Participation /5 + Absence /5 + Cahier /5 + Travail /5
Note générale = moyenne des contrôles × 0.75 + Activités × 0.25
(2 contrôles; 3 in 2BAC SVT)
  • ⏱ full history of a student · Export CSV for Excel.

4QR answer cardsno phones needed

  1. Choose a Banque de questions SVT, press Question suivante ▸: question + 4 choices on the projector, correct letter already set.
  2. 📷 Start scanning and sweep the camera slowly over the class. Numbers turn green.
  3. Reveal answers, discuss, then Save result (optional: +points for correct answers). The camera stays on for the next question.

5Phone quiz

  1. + New quiz → pick a bank → Add these questions; set questions per student, time, code. Save.
  2. Open, then Publish. Write the code on the board.
  3. At the end: Results → 📷 Scan result codes on each phone → Copy into Contrôle if wanted.
Removed students show in red with the reason. No result = did not take the quiz.

6Publish for studentsonce or twice a week

  1. Build & download portal.json.
  2. GitHub → repository → branch claude/attendance-register-app-htpei6 → folder classkit/data/ → Add file → Upload files → Commit.
  3. One minute later, students see the new grades.
  4. Faster: add a GitHub token in Publish, then just press Build & push to GitHub.

7Keep your data safe

  • Data lives in this browser only: always use the same laptop/browser.
  • Settings → Download backup every week (USB key / e-mail to yourself).
  • New device? Restore backup… there.
  • Lost PIN: Students & PINs → New PIN, then Publish.
  • Never use private/incognito mode.
